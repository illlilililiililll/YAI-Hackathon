# AI 작업 기록 (BMAD 스펙)

해커톤 기간(2026.08.01–02)에 OpenAI Codex + BMAD 스펙 우선 워크플로로 작업하며 남긴 문서 중 일부입니다.
각 스펙은 사람이 승인한 의도(`frozen-after-approval`)와 Always / Ask First / Never 경계, 예외 상황 표, 인수 조건, 검증 결과로 구성됩니다.

| 문서 | 내용 |
|---|---|
| [spec-hackathon-e2e-completion.md](spec-hackathon-e2e-completion.md) | 키워드 한 줄로 수집 → 공식 출처 조사 → 글 작성 → 품질 검증 → 렌더링까지 잇는 종단 경로 스펙 |
| [spec-require-five-field-commercial-input.md](spec-require-five-field-commercial-input.md) | 추론·기본값을 없애고 5개 명시 입력만 허용하는 입력 계약 스펙 (관찰된 테스트 결과 포함) |
| [deferred-work.md](deferred-work.md) | 시간 안에 끝내지 못해 통과시키지 않고 미룬 검증 항목 목록 |

원본 파일 그대로이며, 내부 경로·비밀값은 포함되어 있지 않습니다.
