## 우선순위 평가 기준

각 후보 키워드를 다음 기준으로 종합 평가하세요.

- 트윗 핵심 내용과의 직접적인 연관성
- 실제 사용자가 검색할 가능성
- 핵심 키워드에 대해 새로운 정보를 제공하는 정도
- 경쟁 제품, 성능, 비교, 평가 등 검색 의도가 분명한 정도
- SEO 콘텐츠로 확장하기 쉬운 정도
- 트윗에서 명시적으로 언급되거나 강하게 암시된 정도

다음 유형의 단어에 높은 우선순위를 부여하세요.

1. 성능 및 벤치마크
2. 경쟁 제품 또는 비교 대상
3. 핵심 기능 및 기술
4. 가격, 출시, 공개, 사용법 등 주요 정보
5. 개발 기업, 국가 또는 관련 인물
6. 모델 크기, 파라미터, 속도 등 구체적인 특징

## 키워드 생성 규칙

- 모든 결과는 반드시 `핵심 키워드 + 연관 단어` 형태로 작성하세요.
- 핵심 키워드는 각 결과의 맨 앞에 원문 그대로 유지하세요.
- 핵심 키워드 뒤에는 연관 단어를 하나만 붙이세요.
- 한 줄에 하나의 키워드만 작성하세요.
- 서로 의미가 겹치는 키워드는 하나만 선택하세요.
- 핵심 키워드 자체와 의미가 같은 표현은 제외하세요.
- 트윗과 관련 없는 추측성 키워드는 제외하세요.
- 감정 표현과 검색 가치가 낮은 단어는 제외하세요.
- 지나치게 포괄적인 단어보다 검색 의도가 명확한 단어를 우선하세요.

## 출력 규칙

- 각 키워드는 문자열로 작성하세요.
- Python List 외에는 어떤 문장도 출력하지 마세요.
- 코드 블록을 사용하지 마세요.
- 번호, 글머리 기호, 점수, 설명을 작성하지 마세요.
- 반드시 Python에서 바로 사용할 수 있는 유효한 리스트 문법으로 출력하세요.
